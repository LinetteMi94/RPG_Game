# RPG_Game

Консольная ролевая игра на C#.

## О проекте

RPG Game — учебный проект, созданный для практики объектно-ориентированного программирования.
Игрок создаёт персонажа выбранного класса, исследует мир, сражается с монстрами, получает опыт, золото и предметы.


## Используемые технологии

- C#
- .NET 8
- OOP
- Interfaces
- Events
- Collections
- Git
