# RPG_Game

Консольная ролевая игра на C#.

## О проекте

RPG Game — учебный проект, созданный для практики объектно-ориентированного программирования.
Игрок создаёт персонажа выбранного класса, исследует мир, сражается с монстрами, получает опыт, золото и предметы и развивает своего персонажа.


## Используемые технологии

- C#
- .NET 8
- OOP
- Interfaces
- Events
- Collections
- Git

## Реализовано

### Персонажи
- 9 классов героя:
    - Воин
    - Паладин
    - Пират
    - Маг
    - Жрец
    - Друид
    - Охотник
    - Шаман
    - Варлок
  
Персонажи обладают различными характеристиками, способностями и игровыми механиками.

### Монстры
- Крыса
- Гоблин
- Зомби
- Лесной тролль
- Огненный элементаль
- Лепрекон

Монстры имеют собственные характеристики, способности и уникальные механики.

### Боевая система
- Пошаговые сражения
- Атаки и промахи
- Уникальные способности персонажей
- Заклинания
- Расход и восстановление ресурсов
- Лечение
- Специальные эффекты монстров

### Система прогрессии
- Опыт
- Уровни
- Рост характеристик
- Изменение характеристик при повышении уровня
- Награды за победу

### Инвентарь и предметы
- Получение добычи
- Хранение предметов
- Просмотр инвентаря
- Удаление предметов
- Стоимость предметов
- Получение случайных предметов во время путешествий


### Игровая система
- Игровой цикл
- Главное меню
- Меню боя
- Система случайных встреч
- Случайные встречи с монстрами
- Отдых и восстановление здоровья
- Game Over
