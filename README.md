# Game Project

Учебный проект на C# в рамках практики по ООП.

## О проекте

Консольная игра, созданная для практики принципов
объектно-ориентированного программирования.

## Используемые технологии

- C#
- .NET
- ООП

## Реализовано

- наследование
- абстрактный базовый класс Character
- классы Hero и Monster
- характеристики персонажей
- здоровье и лечение
- атака и получение урона

## Статус

В разработке.
