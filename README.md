# RPG_Game

Консольная ролевая игра на C#.

## О проекте

RPG Game — учебный проект, созданный для практики объектно-ориентированного программирования.
Игрок создаёт персонажа выбранного класса, исследует мир, сражается с монстрами, получает опыт, золото и предметы и развивает своего персонажа.


## Используемые технологии

- C#
- .NET 8
- OOP
- Interfaces
- Events
- Collections
- Git

## Реализовано

### Персонажи
- 9 классов героя:
    - Воин
    - Менестрель
    - Пират
    - Маг
    - Астромант
    - Друид
    - Следопыт
    - Шаман
    - Колдун
  
Персонажи обладают различными характеристиками, способностями и игровыми механиками.

Для разных классов используются различные игровые ресурсы:

- Ярость
- Азарт
- Концентрация
- Мана
- Ноты
- Астральная энергия

### Монстры
- Крыса
- Гоблин
- Зомби
- Лесной тролль
- Огненный элементаль
- Лепрекон

Монстры имеют собственные характеристики, способности и уникальные механики.

### Боевая система
- Пошаговые сражения

- Классовые ресурсы
- Расход и восстановление ресурсов
- Лечение
- Специальные эффекты монстров
- События окончания боя

- Получение опыта

- Изменение характеристик при повышении уровня
- Награды за победу
- События повышения уровня

### Инвентарь и предметы
- Получение добычи

- Удаление предметов
- Стоимость предметов

### Игровая система
